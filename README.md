# EaseIntro API

**REST API для управления мероприятиями с QR-код верификацией**

Создавайте приложения для организации мероприятий без необходимости разрабатывать сложную backend-логику. EaseIntro API предоставляет готовое решение для регистрации участников, генерации QR-кодов и контроля посещаемости — всё, что нужно для современного event-менеджмента.

## Что это даёт разработчикам?

### Готовое решение из коробки

Не тратьте месяцы на разработку системы регистрации, генерации QR-кодов и верификации. EaseIntro API предоставляет все необходимые функции через простой REST API. Сосредоточьтесь на создании отличного пользовательского опыта, а не на backend-логике.

### Гибкость интеграции

API работает с любым стеком технологий. Создавайте веб-приложения на React, Vue или Angular, мобильные приложения на iOS и Android, или интегрируйте в существующие системы. Все взаимодействия происходят через стандартные HTTP-запросы.

### Масштабируемость

API спроектирован для работы с мероприятиями любого масштаба — от небольших митапов на 20 человек до крупных конференций на 1000+ участников. Система автоматически обрабатывает нагрузку и обеспечивает стабильную работу.

## Возможности API

### Управление мероприятиями

Создавайте, редактируйте и управляйте мероприятиями через простые API-запросы. Настраивайте лимиты участников, разрешайте приглашение гостей (+1), отслеживайте статусы. Вся информация о мероприятии доступна по уникальному идентификатору — идеально для публичных страниц регистрации.

### Автоматическая регистрация участников

Участники могут регистрироваться самостоятельно через публичные эндпоинты. API автоматически генерирует уникальные QR-коды для каждого участника, проверяет дубликаты и обеспечивает целостность данных. Вам не нужно думать о логике регистрации — просто отправляйте запросы.

### QR-коды и верификация

API генерирует QR-коды автоматически и предоставляет их в виде изображений. Умная система сканирования учитывает время мероприятия: если указано конкретное время, сканирование доступно за 3 часа до начала; если только дата — в день мероприятия. Каждый QR-код можно использовать только один раз, что обеспечивает безопасность.

### Аналитика и отчёты

Получайте статистику посещаемости в реальном времени. API предоставляет информацию о том, кто пришёл, во сколько, и общее количество участников. Экспортируйте данные в CSV для дальнейшего анализа или интеграции с другими системами.

### Безопасная аутентификация

JWT-токены обеспечивают безопасный доступ к защищённым эндпоинтам. Простая система регистрации и входа позволяет быстро интегрировать авторизацию в ваше приложение.

## Примеры использования

### Мобильное приложение для конференций

Создайте нативное iOS или Android приложение, которое позволяет организаторам создавать мероприятия, а участникам — регистрироваться и получать QR-коды. Используйте камеру смартфона для сканирования QR-кодов на входе.

### Веб-платформа для event-менеджмента

Постройте полноценную веб-платформу для управления мероприятиями. Используйте API для всех backend-операций, а фронтенд создайте на любом современном фреймворке. Публичные эндпоинты позволяют участникам регистрироваться без авторизации.

### Интеграция с существующими системами

Добавьте функционал управления мероприятиями в ваше CRM, систему управления сотрудниками или образовательную платформу. API легко интегрируется через стандартные HTTP-запросы.

### Корпоративные решения

Используйте API для создания внутренних систем управления корпоративными событиями. Контроль посещаемости, автоматическая отчётность, интеграция с HR-системами — всё это становится доступным через простые API-вызовы.

## Технические детали

API построен на ASP.NET Core и предоставляет RESTful интерфейс. Поддерживается JWT-аутентификация для защищённых эндпоинтов. Все данные передаются в формате JSON. Подробная техническая документация доступна в отдельных файлах проекта.
